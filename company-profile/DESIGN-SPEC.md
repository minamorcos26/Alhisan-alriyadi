# Design Specification — Alhisan Alriyadi Company Profile (26 pages)

Canvas: 13.33" × 7.5" (widescreen). Margins: 0.8" left/right, 0.5"–0.9" top/bottom.
Global palette: Green `#14532D` (primary), Dark Green `#0F3D22`, Soft Green `#E7F0EA`, Ink `#171717`, Ink-soft `#404040`, White `#FFFFFF`, Off-white `#FAFAFA`.
Global type: Display — Bebas Neue (EN headlines) / bold Tajawal (AR headlines); Body — Source Sans Pro (EN) / Tajawal (AR).
Global icon family: single-weight outline/solid line icons (FontAwesome-style), used inside circular green badges — one family throughout, never mixed.
Global motif: rounded cards + circular icon badges + soft shadows; no accent stripes or underlines.

Each entry below: **Objective → Layout → Images → Icons → Infographic/Data → CTA**

---

**01 · Cover** — Objective: instant brand recognition + premium first impression. Layout: full-bleed dark green, bilingual wordmark left-aligned, logo emblem card right. Images: none (brand-forward cover); optional full-bleed lifestyle photo behind a green overlay as an alternative treatment. Icons: football/emblem mark only. CTA: none — sets tone.

**02 · Table of Contents** — Objective: orient the reader. Layout: two-column numbered list, EN left / AR right per row. Images/Icons: none, typography-led. CTA: none.

**03 · Welcome Message** — Objective: build trust via a personal voice. Layout: text block left, portrait/photo right. Images: leadership portrait or brand ambassador in action. Icon: handshake. CTA: none (sets relationship tone for the rest of the document).

**04 · Who We Are** — Objective: define the company in one paragraph. Layout: image left, text right (alternating rhythm starts here). Images: multi-category product flat-lay. Icon: verified/shield.

**05 · Our Story** — Objective: humanize the brand's growth. Layout: text left, image right. Images: warehouse/packing/operations. Icon: star. Data: milestone note flagged as placeholder pending client confirmation.

**06 · Vision** — Objective: one aspirational sentence, big type. Layout: image left, oversized quote-style text right. Images: wide lifestyle action shot. Icon: compass.

**07 · Mission** — Objective: one operating-principle sentence. Layout: text left, image right. Images: delivery/courier moment. Icon: target/bullseye.

**08 · Core Values** — Objective: scannable value system. Layout: 3×2 card grid, icon-in-circle + EN/AR label + one-line proof point per card. Icons: shield-check (Authenticity), handshake (Trust), bolt (Speed), globe (Accessibility), users (Community), star (Quality). Infographic: the grid itself functions as the value framework.

**09 · Why Alhisan Alriyadi** — Objective: competitive-advantage scorecard. Layout: 2×3 horizontal cards, icon left / EN+AR label right. Icons: shield-check, truck, boxes, lock, star, headset. Data: six proof points (authenticity, delivery, category breadth, secure payment, returns, support).

**10 · Our Product Universe** — Objective: category map at a glance. Layout: dark-green full-bleed background, 5×2 tile grid, white icon + EN/AR label per tile. Icons: one per category (football, dumbbell, swimmer, kimono, racket, basketball, child, tent, t-shirt, bag). This page doubles as a visual index for pages 11–20.

**11 · Football** — Objective/Layout: category template (repeats through p.20) — big number, icon badge, EN/AR title, one-line description, 2-column "What We Offer" bullet list, large image panel alternating sides. Images: player/product action shot. Icon: football.

## QR code placement
Back Cover (p.26) and Contact Us (p.25), bottom-right, ~1" square, on a white/light zone for scan contrast, linking to `athletic-horse.com` or the WhatsApp chat link.

## Print-ready notes
- Bleed: add 0.125" bleed + 0.25" safe margin if sending to a commercial printer; the current file has no bleed built in (screen/PDF-first deck).
- Color mode: convert green palette to CMYK before print (`#14532D` ≈ C77 M35 Y75 K33) and proof against the digital hex before final run.
- Binding: works as a saddle-stitched or perfect-bound booklet at 26 pages; category pages (11–20) are designed to survive being reordered or trimmed if the printed version needs to be shorter.
